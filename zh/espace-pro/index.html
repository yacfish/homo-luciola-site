介绍

Homo-Luciola 是 Cie LaterrateraL 与 Fōz Machine 的集体创作。

这是一部混合型演出，舞蹈身体的垂直性与互动装置 Fōz Machine 对话。上升与悬挂的动作成为 Fōz Machine 投射出的光之向量，在垂直空间中写下转瞬即逝的视觉书写。

它处于垂直舞蹈、造型与数字艺术、视听、壁面艺术与都市艺术的交汇处。

创作现状

约40分钟的形式已经可以成立：观众看到美而令人满足的东西，同时也知道许多元素仍可改进。这一形式并非定稿。写作、戏剧结构、编舞、声音与影像的工作仍在继续，包括修改已有场次并创作新的场次（最近一场演出已这样做过）。

就巡演而言，可由这些场次组合成一刻钟至20分钟的较短形式，适配节日、主题、立面或场地。可根据语境保留一场、两场或三场。

来源：2026年11月16日的工作交流（录音1，以及 Yacine 与其合作者的讲述）。

技术说明书

以下数字汇总已拟就的技术说明书（驻留说明书、简版、2026年9月说明书）以及目前为资料所保留的需求。若某一数值在各说明书之间不一致或缺失，则标以 [à confirmer]。

形式

现场演出、垂直舞蹈与互动装置。观众：适合所有观众。容量按场地调整。

时长

主要形式约40分钟，另有8至15分钟的短形式。为完整编制通报的参考价对这两种时长相同。

可用垂直高度

8至10米。三份技术说明书在此区间上一致。

吊点高度

在可用高度之上：+1至5米，或按各说明书为 +2至5米 [à confirmer]。

宽度

约10米。

最小进深

按各说明书为7米或10米，外加观众空间 [à confirmer]。

吊点

本资料目前保留的需求：至少4个承重500公斤的点 [à confirmer]。技术说明书通常写明悬挂桁架的3个点，外加拉索与配重点，每点最小承重5千牛（约500公斤）。吊点方案的细节取决于场地，仍为 [à confirmer]。

暗度

强暗或全黑，为 Fōz Machine 的光捕捉所需。一份说明书也写明照明可采用可接受的暮色。巡演安排在夜间。[à confirmer]

供电

220 V，配电点靠近 Fōz Machine 与控制台。总功率（千瓦）取决于投影规模，尚未有确定数字。对于约20,000至24,000流明的投影机，是否需要三相电尚未确定。

搭台时间

一场演出需在现场安排三到四天：一天搭台、一夜排练、一个下午排练、一个晚上演出。若主办方需租用视频投影机，租期同样覆盖这三天或四天。垂直结构的搭装为一天，Fōz Machine 的安装与校准（半天）包含在该日之内。若团队的吊挂系统无法安置，主办方聘请脚手架公司，在两名吊装员监督下安装安全脚手架。

巡演团队

已通报的完整编制最多六人（三名垂直舞者、一名垂直舞者及另外两名艺术家），其中包括 Yacine。更精简的编制也可行（两名垂直舞者，无音乐家）。Noé 是垂直舞者兼吊装技术员。

灯光

视频投影机由主办方提供。已通报的规则是：每米宽度约1,000流明（例如20米宽的舞台需20,000流明），若墙面为黑色或吸光很强，则再略增。辅助投影机的数量与类型仍随已写就的技术说明书而有所不同。

音响

音响由主办方提供。一份说明书写明 2.2 系统、立体声或立面扩散，以及2只返听 [à confirmer le détail selon le lieu]。

勘察

视场地预先进行可行性研究。吊点图、示意图以及安全或保险文件：按需提供。

后勤

车辆进出及3至4辆免费停车、器材安全存放、带卫生设施的安全供暖化妆间。表演区护栏；若为公共空间则需看守。一份说明书提到6人餐饮，其中2人为素食 [à confirmer]。

演出费与形式

约40分钟的形式完整编制约5,000 €（三名垂直舞者、一名“光”表演者、一名音乐家及一名视频技师；一天搭台、一夜排练、一个下午排练、一个晚上演出）。金额可视场地及所提供条件而变动。
8至15分钟的短形式与约40分钟形式相同的参考价，完整编制约5,000 €。金额可视场地及所提供条件而变动。

巡演条件

巡演最多六人（三名垂直舞者、一名垂直舞者及另外两名艺术家），需为他们安排酒店与餐饮。更精简的编制也可行（两名垂直舞者，无音乐家）。器材以面包车运送；使用一辆面包车和一辆轿车。各人从自己家出发；出发集合点在 Ath（比利时）一带，Yacine 从布鲁塞尔前来。一场演出需在现场三到四天。
